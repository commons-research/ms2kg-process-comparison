
# MS2KG ETL pipelines evaluations

## Context

In multiple research projects of differents labs (COMMONS Lab, Wolfender, SIB, Zamboni lab) knowledge graphs are built form enriched mass spectrometry based datasets following ETL (extract, transform and load) pipelines. Example of public KGs generated by such pipelines are ([ENPKG](https://kg.earthmetabolome.org/), [METRIN-KG](https://kg.earthmetabolome.org/)). 
All KGs where build through different processes and have used different scheams. As a result they are poorly overlapping. This is an issue as the purpose of [Linked Open Data](https://5stardata.info/en/) is not achieved.

## Need

Appropriate tooling and schemas to generate KGs in a reproducible and versionable manner.

## Task

Share, document and compare workflows required to convert the following [toy-dataset](https://zenodo.org/records/10018590) to a KG.
